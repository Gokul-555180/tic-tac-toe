# Tic Tac Toe (React + Vite)

Simple Tic-Tac-Toe game built with React and Vite.

How to run

1. Install dependencies:

```
npm install
```

2. Run dev server:

```
npm run dev
```

3. Open http://localhost:5173

Run tests (Vitest):

```
npm test
```

Windows PowerShell note: if PowerShell blocks scripts, run the commands in a terminal that has npm available (regular PowerShell or Windows Terminal). The commands above have been tested on standard Node.js/npm setups.
